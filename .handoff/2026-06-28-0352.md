## What was done

### Plugin loading fix — glob issue
- **Diagnosed**: Plugin not loading. `opencode debug info` only showed npm plugins.
- **Root cause**: OpenCode uses glob `{plugin,plugins}/*.{ts,js}` — only matches files directly in `plugins/`, not subdirectories (issue [#6866](https://github.com/anomalyco/opencode/issues/6866))
- **Fix**: Moved from `~/.config/opencode/plugins/opencode-model-failover/index.js` to `~/.config/opencode/plugins/model-failover.js`

### Repo updates
- **tsup.config.ts**: entry renamed `"model-failover": "src/index.ts"` → outputs `dist/model-failover.js`
