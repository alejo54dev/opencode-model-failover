# Handoff — Model Failover Plugin (built + deployed)

## State

Plugin fully implemented, typechecks, and deployed to `~/.config/opencode/plugins/model-failover.js`

## Source files

| File | Purpose |
|------|---------|
| `src/index.ts` | Main plugin — event handlers (`session.error`, `session.status`, `session.deleted`), `chat.message` hook, `executeFailover`, `tryFallbackChain`, `rePrompt` |
| `src/config.ts` | Config loader from `~/.config/opencode/model-failover.json`, `parseModel`, `modelKey` |

## Architecture

1. `session.error` / `session.status` classify errors via `classify()` → `"immediate"` or `"retry"`
2. On either branch, `executeFailover(sessionID, config, client)` runs:
   - Aborts current streaming request
   - Iterates `fallbackChain`, skipping models in cooldown
   - Calls `rePrompt()` with `{ model: { providerID, modelID }, parts: [{ type: "text", text: "Continue" }] }`
   - On success: stores model in `failoverModels` Map, logs `✅ failover to ...`
   - On exhaustion: logs `❌ fallback chain exhausted`
3. `chat.message` hook fires on every user message — checks `failoverModels.get(sessionID)` and overrides `output.message.model`
4. Cleanup: `session.deleted` removes session + failover model; `cleanupStaleState` purges old cooldowns/sessions every 5 min
